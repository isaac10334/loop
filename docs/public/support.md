# Capability and support catalog

Implementation support is separate from authorization. **Supported** means an implemented preview path with the verification described below, not a published package or platform-wide guarantee. Experimental paths have material limits. Proposed, unsupported and untested are distinct statuses; absence of a row proves nothing.

The website generates the matrix and detailed restrictions from the structured [support catalog](../../site/support.ts); a [JSON copy](https://isaac10334.github.io/loop/docs/support.json) is available to tools. WIT rows use exact interface identities. SDK and platform rows describe APIs, not acquirable capabilities. See [installation](installation.md) for distribution status and [compatibility](compatibility.md) for language roles.
