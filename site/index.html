Write your application in Rust. Run it in a native host with explicit access to capabilities. Create, run, and package it with Loop.

Install Loop

Windows x64 · PowerShell
powershell -c "irm https://isaac10334.github.io/loop/install.ps1 | iex"

Installs the CLI and its Rust toolchain for your user account.

Keep your existing Rust default. Open a new terminal after installation.

Download ZIPRead the installerRelease notes

Make something

loop create hello
loop run hello
loop build hello

Share the generated application directory. Recipients don't need Loop or Rust.

Keep it simple

loop upgrade
loop uninstall

Wait for the manager's completion message. Uninstall keeps your projects and Rust tools. Windows Settings also lists Loop CLI.

Early preview. Windows 11 x64. Building apps requires Microsoft C++ Build Tools and the Windows SDK. Desktop windows require WebView2. Setup instructions.
