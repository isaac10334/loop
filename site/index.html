An application, a provider, one owned lifetime.

This is the counter example running through the official browser kit and semantic DOM renderer. Change the amount, use the button with pointer or keyboard, then stop the application. Restart creates fresh provider state.

The application has no renderer-specific controls. Its provider owns the count; the kit owns the surface and cleanup.

Keep the service; replace the implementation.

Use typed providers for storage, commands or application state. Composition chooses the implementation; scopes own acquisitions and cleanup.

const clock = defineCapability<Clock>({
  id: "loop:time/clock",
  version: "1.0.0",
});

const handle = await scope.acquire(clock);
console.log(handle.value.now());
await handle.release();

Choose where the application runs.

The browser kit composes TypeScript services and DOM presentation. The native kit uses Rust, Wasmtime and Tao/Wry on Windows. Components use specific reviewed worlds and grants—not arbitrary host access.
